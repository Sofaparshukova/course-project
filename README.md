Курсовой проект: Умная кухня



Программа для автоматизации управления процессами на умной кухне.

Позволяет пользователю:

\- планировать приготовление блюд;

\- контролировать наличие и сроки годности продуктов;

\- управлять кухонной техникой;

\- получать рекомендации по рецептам;

\- формировать список покупок.
